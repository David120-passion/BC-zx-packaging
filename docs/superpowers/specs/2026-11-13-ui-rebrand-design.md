## 1. 目标与范围

在保留现有打印、称重、配置、标签模板和设备驱动行为的前提下，将当前以 `TabPane` 为主的最小验证界面重构为统一、精致、可用于工业桌面的 JavaFX 界面，并补齐启动动画和应用图标。

本次覆盖：

- 主窗口导航、页面标题、内容容器与全局操作日志。
- 打印测试、称重测试、系统配置、标签设计四个现有页面。
- 全局设计令牌、控件样式、页面切换动效、空状态与忙碌状态。
- 无边框启动页、真实启动阶段提示、启动失败反馈及主窗口过渡。
- 原创应用图标及启动页、侧边栏、窗口和任务栏图标接入。
- 自动化测试与实际启动后的桌面 UI 验证。

明确不做：

- 不新增 A/B 线生产页面或静态页面外壳。

## 3. UI 架构与组件边界

### 3.1 主框架

`MainView` 从顶部 `TabPane` 改为：

```text
┌──────────────┬───────────────────────────────────────────┐
│ 应用图标/名称 │ 页面标题、说明、当前操作状态               │
│              ├───────────────────────────────────────────┤
│ 打印测试     │                                           │
│ 称重测试     │ 当前页面内容（四页只构建一次并缓存）       │
│ 系统配置     │                                           │
│ 标签设计     │                                           │
│              ├───────────────────────────────────────────┤
│ 本地运行信息 │ 可折叠操作日志抽屉                         │
└──────────────┴───────────────────────────────────────────┘
```

- 左侧导航宽约 210px，使用彩色圆角图标块和白色选中项。
- 四个页面缓存于 `StackPane`，切换只替换可见页并以 180ms 淡入，保留输入和编辑状态。
- 顶栏只显示真实页面信息和操作状态，不显示虚构的 MES 或设备连接状态。
- 底部日志抽屉默认展示最近日志，支持展开、收起、清空和自动滚动。
- 默认窗口约 `1360×900`，最小尺寸 `1180×720`；场景填充色与页面背景一致，避免缩放黑边。
- 页面主内容使用外边距和卡片间距形成层次，局部滚动代替整个窗口失控撑大。

### 3.2 通用组件

| 组件 | 职责 |
|---|---|
| `SidebarNav` | 应用标识、四个单选导航项、选中索引、本地运行信息和版本 |
| `ResultBanner` | 运行、成功、失败状态；任意线程调用，FX 线程更新；固定高度避免布局跳动 |
| `LogDrawer` | 最近 500 条日志、分级颜色、清空、展开/收起、自动滚动和长日志横向查看 |
| `SplashScreen` | 启动卡片、图标动效、状态文字、版本、完成淡出和失败关闭 |
| `AppInfo` | 从构建期注入的版本资源读取版本，IDE 未过滤时显示 `dev` |

样式类沿用参考项目的语义命名，如 `card`、`card-title`、`btn-primary`、`field-label`、`result-banner`、`log-list`，减少无效命名分叉。颜色、字体和共享尺寸进入 `app.css`，业务页面不写重复的内联主题。

后台 I/O 仍由现有面板的后台 daemon 线程执行。所有控件状态、日志列表和动画更新必须回到 JavaFX 应用线程。忙碌状态只禁用当前页面的相关操作，不阻塞其他页面导航。

## 4. 页面设计

### 4.1 打印测试

布局为左侧模板与变量区、右侧打印操作卡：

- 模板卡：模板下拉框、刷新按钮、模板变量提示。
- 变量卡：根据 `PrintService.templateVariables()` 动态生成表单，变量切换后清理旧字段。
- 操作卡：查询打印机状态、打印；打印为蓝色主按钮。
- 标题行放置 `ResultBanner`，显示查询中、打印中、成功和失败。
- 查询或打印期间禁用对应按钮，打印期间禁止修改变量和切换模板，防止输入快照与执行内容不一致。
- 打印调用仍使用进入后台任务时捕获的模板名和变量快照，继续经过 `PrintService.print()` 与打印前状态检查。
- 无模板时展示空状态并禁用打印，不发起无效请求。

### 4.2 称重测试

主卡片采用大号等宽数字和独立单位：

- 初始显示 `—` 和 `g`，不伪造 0 或稳定重量。
- 读取稳定重量和去皮/清零为两个独立操作。
- 操作期间显示对应状态并禁用两个按钮，避免同一串口被并发打开。
- 读取成功后显示 `ScaleService.readStableWeight()` 返回值；去皮成功后保持重量为空，并提示重新读取。
- 超载、超时、非克单位、串口打开失败等沿用现有异常文案，通过红色横幅和日志显示。
- 配置摘要仅显示串口名和读取超时，不宣称设备在线。

### 4.3 系统配置

按设备分为两张卡片：

- 标签打印机：主机、端口、DPI。
- 电子秤：串口、稳定重量读取超时。
- 保留 `ConfigKeys.DEFAULTS` 的五个键和 `ConfigService.saveAll()` 的持久化路径。
- 标签显示中文名称，字段旁或下方显示配置键与简短单位，便于与文档对应。
- 端口为 1–65535 的整数；DPI 和读取超时为正整数。非法输入在字段下显示提示并阻止本次保存，不写库。
- “保存配置”使用主按钮，“还原修改”恢复为当前已保存值，不重置为出厂默认。
- 保存期间禁用保存和还原；结果通过横幅与日志反馈。
- 配置面板修改后，打印和称重页面下次操作时继续从现有 `ConfigService` 缓存读取新值。

### 4.4 标签设计

采用三栏工作区：

- 左栏约 200px：模板列表、新建、删除；内置模板显示“内置”标记。
- 中栏：工具栏、可滚动画布和空状态；画布使用中性背景、白色标签纸、选中框和清晰边界。
- 右栏约 280px：元素类型、坐标和类型特有属性，使用分组卡片与局部滚动。
- 保存和测试打印置于明确工具栏位置；保存继续使用打开模板时的名称和 JSON 快照，避免后台保存期间切换模板造成竞态。
- 保留现有拖拽、属性应用、模板 CRUD 和内置模板不可删除规则。
- 测试打印先弹出变量录入表单；变量从 `PrintService.templateVariables()` 获取，确认时捕获名称与变量快照，再调用原打印服务。取消则不执行 I/O。
- 无选中模板或无选中元素时显示对应空状态，不展示无意义表单。
- 删除为破坏性本地操作，弹出确认；内置模板仍由仓储拒绝删除。

## 5. 全局日志

`UiLogService` 继续作为唯一日志来源，`LogDrawer` 只负责展示：

- 最多显示 500 条，与现有限制一致。
- INFO 使用正常文字，WARN 使用橙色，ERROR 使用红色。
- 新日志自动滚动到底部；用户收起抽屉时不强制展开。
- 支持清空显示列表和手动展开/收起。
- 长日志通过实测文本宽度提供横向滚动，悬停可查看完整内容。
- 日志文件写入仍由现有 Logback 配置负责，不新增第二份业务日志。

## 6. 启动动画与应用入口

`MainApp.start()` 调整为以下顺序：

1. 加载内嵌字体和多尺寸应用图标。
2. 创建并显示 `SplashScreen`。
3. 后台创建 `data` 目录，更新“正在准备本地数据…”。
4. 后台启动 Spring，更新“正在启动服务容器…”。
5. FX 线程构建主场景，更新“正在加载主界面…”。
6. 启动页 320ms 淡出并关闭，主窗口约 300ms 淡入。

启动页样式：

- `StageStyle.TRANSPARENT`，透明无边框窗口和白色 24px 圆角卡片。
- 图标约 88px，首次 420ms 淡入并从 0.94 放大到 1.0。
- 图标呼吸周期约 1500ms，缩放范围 1.0–1.045，启动页关闭时停止动画。
- 应用名为“IOL 包装线上位机”，辅以包装/标签系统副标题、3px 细进度条、真实状态文字和版本号。
- 不设置人为最短展示时间，正常启动速度优先。

启动失败时记录异常、停止动画、关闭启动页并显示错误对话框；用户确认后退出。Spring 上下文仍在 `stop()` 中关闭，避免后台资源泄漏。

版本通过 `version.properties` 在 Maven 构建期从 `pom.xml` 注入；资源过滤只覆盖版本文件及必要配置，字体、PNG、SVG、ICO 始终原样复制。

## 9. 错误处理与线程约束

- UI 事件只做输入捕获、状态切换和后台任务提交，不直接执行阻塞 I/O。
- 每个面板跟踪自己的忙碌状态，异常统一进入 `ResultBanner` 和 `UiLogService`。
- 后台任务使用模板名、变量和设计的不可变快照，避免执行过程中 UI 修改改变任务内容。
- 所有 `Platform.runLater()` 更新先检查对应控件场景是否仍有效，避免应用关闭后更新已销毁页面。
- 启动动画和所有 `Transition` 必须在关闭时停止。
- 不添加空 `try/catch`，不将失败伪装成成功，不吞掉设备异常。
- 不根据配置值推断连接状态；只有真实操作成功才显示操作成功。

### 10.2 实际桌面验证

使用项目标准 JavaFX 启动方式运行真实应用，并检查：

1. 启动页在 Spring 就绪前可见，图标、中文字体、进度和版本正常。
2. 启动完成后无启动页残留，主窗口和任务栏图标正确。
3. 四个导航页可反复切换，页面输入状态保留，无空选中项。
4. 打印页变量表单随模板切换，未选择模板时不能打印。
5. 称重页初始无伪造读数，忙碌状态与错误展示布局稳定。
6. 配置非法值不写库，还原文本正确，保存状态可见。
7. 标签设计器模板列表、画布、属性区、局部滚动、变量弹窗和删除确认可用。
8. 日志抽屉展开、收起、清空、自动滚动和长日志显示正常。
9. `1360×900` 与 `1180×720` 下无关键按钮被遮挡、文字乱码或整页失控横向滚动。
10. 关闭应用后无启动动画或非 daemon UI 线程阻止退出。

桌面验证不点击真实“打印”“读取稳定重量”“去皮/清零”，除非用户另行提供并授权可用设备。最终报告明确区分自动化、桌面 UI 和未执行的真机验收。
